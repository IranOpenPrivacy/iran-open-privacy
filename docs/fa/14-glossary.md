# واژه‌نامه

| واژهٔ فارسی | معادل انگلیسی | توضیح |
| --- | --- | --- |
| دادهٔ شخصی | Personal data | هر داده‌ای که به یک شخص مشخص، یا شخصی که بشود شناسایی‌اش کرد، مربوط باشد |
| صاحب داده | Data subject | کسی که داده دربارهٔ اوست |
| کنترل‌کننده | Controller | کسی که تعیین می‌کند داده برای چه و چطور پردازش شود |
| پردازشگر / زیرپردازشگر | Processor / Subprocessor | کسی که از طرف کنترل‌کننده (یا از طرف پردازشگر) داده را پردازش می‌کند |
| حوزه | Domain | یکی از ۹ گروه کنترل در چک‌لیست (با دامنهٔ اینترنتی فرق دارد) |
| کنترل | Control | الزامی مشخص در چک‌لیست که می‌شود بررسی‌اش کرد |
| شواهد | Evidence | هر مدرکی که نشان می‌دهد یک کنترل رعایت شده است |
| اظهارشده | Declared | سطح ۱: شرکت اعلام کرده و ابزار خودکار شواهد عمومی را سنجیده |
| تأییدشده | Verified | سطح ۲: بازبین‌ها شواهد را بررسی کرده‌اند |
| تأیید مستمر | Continuously Verified | سطح ۳: تأیید در طول زمان، با ممیز و پایش مداوم |
| بازبین | Reviewer | کسی که برای سطح ۲ شواهد را بررسی می‌کند و از میان بازبین‌های ثبت‌شده انتخاب می‌شود |
| نگهدارنده | Maintainer | کسی که استاندارد و برنامه را پیش می‌برد و تأیید نهایی با اوست |
| ممیز | Auditor | بازرس مستقل و حرفه‌ای که برای سطح ۳ دستمزد می‌گیرد |
| صفحهٔ اعتماد | Trust page | صفحهٔ عمومی هر شرکت با کنترل‌ها، اسناد و زیرپردازشگرها |
| گواهی امضاشده | Signed attestation | فایلی ماشین‌خوان با امضای دیجیتال که سطح و نسخهٔ سند را ثبت می‌کند |
| سند حریم خصوصی | Privacy document | سیاست حریم خصوصی نسخه‌دار هر شرکت روی IOP |
| نسخهٔ عمده | Major version | تغییری در رفتار با داده که مستقیم به کاربر مربوط است |
| تغییر کرده از زمان تأیید | Changed since verified | وضعیتی موقت پس از تغییر عمدهٔ سند، تا وقتی دوباره بررسی شود |
| میزبان مالی | Fiscal host | نهادی که کمک‌های مالی پروژه‌ای بدون نهاد حقوقی را دریافت و نگهداری می‌کند |
| نام مستعار | Pseudonym | نامی ثابت و غیرواقعی که بازبین با آن کار می‌کند |
| شرط پایان مرحله | Gate | شرطی که باید برقرار باشد تا مرحلهٔ بعدی نقشهٔ راه شروع شود |
