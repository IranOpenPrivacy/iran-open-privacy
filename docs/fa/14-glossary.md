# واژه‌نامه

| واژهٔ فارسی | معادل انگلیسی | توضیح |
| --- | --- | --- |
| داده شخصی | Personal data | هر داده مربوط به یک شخص حقیقی مشخص یا قابل شناسایی |
| صاحب داده | Data subject | شخصی که داده به او مربوط است |
| کنترل‌کننده | Controller | کسی که هدف و شیوهٔ پردازش را تعیین می‌کند |
| پردازشگر / زیرپردازشگر | Processor / Subprocessor | کسی که به نام کنترل‌کننده (یا پردازشگر) داده را پردازش می‌کند |
| حوزه | Domain | یکی از ۹ گروه کنترل در چک‌لیست (غیر از دامنهٔ اینترنتی) |
| کنترل | Control | یک الزام مشخص و قابل بررسی در چک‌لیست |
| شواهد | Evidence | هر مدرکی که برقراری یک کنترل را نشان می‌دهد |
| اظهارشده | Declared | سطح ۱: شرکت اظهار کرده و ابزار شواهد عمومی را سنجیده |
| تأییدشده | Verified | سطح ۲: شواهد توسط بازبین‌ها بررسی شده |
| تأیید مستمر | Continuously Verified | سطح ۳: تأیید در طول زمان با ممیز و پایش |
| بازبین | Reviewer | عضو استخر که شواهد را برای سطح ۲ بررسی می‌کند |
| نگهدارنده | Maintainer | کسی که استاندارد و برنامه را اداره و تأیید نهایی می‌کند |
| ممیز | Auditor | بازرس مستقل پولی برای سطح ۳ |
| صفحهٔ اعتماد | Trust page | صفحهٔ عمومی شرکت با کنترل‌ها، اسناد و زیرپردازشگرها |
| گواهی امضاشده | Signed attestation | فایل ماشین‌خوان با امضای دیجیتال دربارهٔ سطح و نسخهٔ سند |
| سند حریم خصوصی | Privacy document | سیاست حریم خصوصی نسخه‌دار هر شرکت روی IOP |
| نسخهٔ عمده | Major version | تغییر در رویهٔ داده که اثر مستقیم بر کاربر دارد |
| تغییر کرده از زمان تأیید | Changed since verified | وضعیت موقتی پس از تغییر عمدهٔ سند |
| میزبان مالی | Fiscal host | نهادی که میزبان کمک‌های مالی یک پروژه بدون نهاد حقوقی است |
| نام مستعار | Pseudonym | نام پایدار غیرواقعی برای بازبین |
| دروازه | Gate | شرط عبور از یک فاز نقشهٔ راه |
