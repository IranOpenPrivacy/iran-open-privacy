# ثبت تعارض منافع

هر نگهدارنده و بازبین تعارض‌های منافعش را اینجا می‌نویسد و هر وقت تغییر کرد، به‌روزش می‌کند. قواعد: [تعارض منافع](../docs/fa/05-conflict-of-interest.md)

## قالب

```yaml
- who: نام یا نام مستعار
  role: maintainer   # maintainer | reviewer | advisor
  company: slug-شرکت
  type: owner        # owner | investor | board | employee | former-employer | contractor | family | sponsor
  since: 2026-01-01
  until: null
```

## ثبت‌ها

```yaml
# هنوز ثبتی وجود ندارد.
# اگر نگهدارنده‌ای شرکتی را اداره می‌کند، در آن سرمایه گذاشته یا عضو هیئت‌مدیرهٔ آن است،
# باید آن را اینجا ثبت کند. آن شرکت نمی‌تواند سطح ۲ یا بالاتر بگیرد.
```
