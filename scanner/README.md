# ابزار بررسی سطح ۱ (مشخصات)

> **وضعیت: فقط مشخصات.** هنوز کدی نوشته نشده است. این سند برای جذب مشارکت‌کنندهٔ فنی در فاز ۲ نقشهٔ راه است. مجوز: AGPL-3.0.

## هدف

بررسی خودکار شواهد **عمومی** یک شرکت برای ۷ کنترلی که `check: auto` دارند. ابزار قضاوت انسانی نمی‌کند و فقط می‌گوید «آنچه از بیرون دیده می‌شود با اظهار شرکت سازگار هست یا نه».

## کنترل‌های خودکار

| کنترل | چه چیزی بررسی می‌شود |
| --- | --- |
| TRN-01 | صفحهٔ سیاست حریم خصوصی از صفحهٔ اصلی و ثبت‌نام بدون ورود قابل دسترسی است (کد پاسخ ۲۰۰) |
| TRN-05 | سند شمارهٔ نسخه، تاریخ و پیوند به تاریخچه دارد؛ پیوند دوطرفه با سند IOP برقرار است و به نسخهٔ فعلی اشاره می‌کند |
| THP-01 | صفحهٔ عمومی فهرست زیرپردازشگرها وجود دارد |
| THP-02 | ردیاب‌ها و SDKهای شناخته‌شدهٔ بارگذاری‌شده در صفحهٔ اصلی با فهرست سند مقایسه می‌شوند |
| SEC-01 | تغییر مسیر HTTP به HTTPS، گواهی معتبر، هدر HSTS |
| SEC-02 | هدرهای امنیتی پایه (مانند `X-Content-Type-Options` و جلوگیری از قرارگیری در قاب) |
| SEC-08 | وجود `/.well-known/security.txt` با فیلد `Contact` و بدون انقضا |

## اصول اخلاقی و فنی

1. **فقط دامنه‌هایی که اثبات مالکیت شده‌اند** بررسی می‌شوند (رکورد DNS یا فایل `/.well-known/iop.txt`).
2. فقط درخواست‌های عمومی و بدون ورود. هیچ رمز، توکن یا حسابی استفاده نمی‌شود.
3. نرخ درخواست پایین، با `User-Agent` معرفی‌کنندهٔ IOP و پیوند به صفحهٔ توضیح.
4. هیچ داده شخصی کاربران جمع‌آوری یا ذخیره نمی‌شود. فقط نتیجهٔ هر کنترل (قبول، رد، نامشخص) و زمان.
5. نتیجه‌ها عمومی و قابل بازتولید هستند. هر شرکت می‌تواند بررسی را خودش اجرا کند.
6. نتیجهٔ «نامشخص» ممکن است (مثلاً سایت در دسترس نیست). ابزار هرگز حدس نمی‌زند.

## خروجی

یک فایل JSON برای هر شرکت و هر اجرا:

```json
{
  "company_slug": "example-company",
  "run_at": "2026-12-01T10:00:00Z",
  "results": [
    { "control": "SEC-01", "status": "pass", "evidence": "https redirect, hsts max-age=31536000" },
    { "control": "SEC-08", "status": "fail", "evidence": "/.well-known/security.txt returned 404" },
    { "control": "THP-02", "status": "unknown", "evidence": "page timed out" }
  ]
}
```

## دامنهٔ فاز ۲ (حداقل)

- SEC-01، SEC-02، SEC-08 و TRN-01 (ساده‌ترین، بدون نیاز به تحلیل صفحه)
- TRN-05 و THP-01 به‌صورت بررسی وجود
- THP-02 (ردیاب‌ها) پس از آن، با فهرست باز ردیاب‌های شناخته‌شده

## مشارکت

یک Issue با برچسب `scanner` باز کنید. زبان پیشنهادی: Python یا Node.js با کمترین وابستگی.
